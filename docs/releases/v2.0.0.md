# Hermes Finance Stack v2.0.0

Major architectural and functional release turning Hermes Finance Stack into a full modular personal, household, and group finance platform over Telegram.

## What's New

- **Modular NestJS 12 Core (`ExpensesModule`, `OutingsModule`, `McpModule`)**: Clean separation into 8 REST controllers and 7 MCP tool registrars (**43 typed MCP tools**, **38 Vitest unit tests**).
- **Single-Hermes Multi-User & Shared Balances**: One Telegram bot handles DMs and shared groups, tracks `PERSONAL` vs `SHARED` spending with custom `%` splits, and calculates minimal household settlements.
- **Group Outings ("Salidas")**: Isolated Splitwise-style events for trips, dinners, and asados—managed by multiple users or dictated by a single user for ad-hoc friends, with equal, subset (`splitBetween`), exact, or percentage splits and optional personal share recording upon closing.
- **Fixed / Recurring Bills**: Define monthly/bimonthly/yearly templates, check unpaid or overdue items each month, and log payments adjusting for actual billed amounts.
- **Category Budgets & Alerts**: Monthly category limits with warning thresholds surfaced automatically in summaries.
- **Native Telegram PNG Charts & CSV/JSON Exports**: Zero-native-build `@resvg/resvg-wasm` charts (`by_category`, `monthly_trend`, `top_expenses`, `fixed_vs_variable`, `by_holder`) and Excel-ready CSV/JSON exports delivered directly in Telegram via `MEDIA:`.
- **Silent Telegram UX & Skills**: Low-noise chat (`👀`/`👍` reactions, no tool narration), PostgreSQL as single source of truth (`memory_enabled: false`), mobile table-free `monthly-summary-format`, and guided `onboarding`.
- **Variable Stack Support**: `health_check` cleanly reports `optionalServices.paperless.status: "disabled"` when running without `--profile paperless`.

## Breaking Changes (REST API)

*(Hermes uses `POST /api/mcp`, which remains fully compatible.)*

- `/api/expenses/installments/*` → `/api/installments/*`
- `/api/expenses/cards` → `/api/credit-cards`
- `/api/expenses/summary` → `/api/analytics/summary`
- New endpoints: `/api/members`, `/api/budgets`, `/api/recurring-expenses`, `/api/analytics`, `/api/outings`

```bash
chmod +x scripts/*.sh
./scripts/migrate.sh --normalize-categories --backfill-owner "YourName"
docker compose up -d --build
./scripts/smoke-test.sh
```
