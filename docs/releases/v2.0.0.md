# Release v2.0.0 — Multi-User, Group Outings, Fixed Expenses, Budgets, PNG Charts & 43 MCP Tools

## Highlights

- **Single-Hermes Multi-User & Shared Balances**: Track personal and shared household expenses (`scope: PERSONAL | SHARED`, percentage `allocations`, and automatic settlement balances) from DMs or a shared Telegram group using one Hermes instance.
- **Group Outings ("Salidas")**: Split trips, dinners, and asados cleanly without polluting personal cashflow. Supports both multi-user chat and single-user dictation for ad-hoc friends, equal/subset/exact/percentage splits, minimal transfer calculation, and optional recording of your own share on close.
- **Fixed / Recurring Expenses**: Define monthly/bimonthly/yearly bill templates, check what is still unpaid or overdue each month, and log payments with inflation-adjusted amounts.
- **Category Budgets & Alerts**: Set monthly category caps with configurable warning thresholds integrated into `get_financial_summary`.
- **Native Telegram PNG Charts & Exports**: Generate 800×480 PNG charts (`by_category`, `monthly_trend`, `top_expenses`, `fixed_vs_variable`, `by_holder`) using `@resvg/resvg-wasm` and export UTF-8 BOM CSV or JSON files delivered directly in Telegram via `MEDIA:`.
- **Silent Telegram UX & Skills**: No tool-call spam, `👀`/`👍` reactions, PostgreSQL as single source of truth (`memory_enabled: false`), mobile table-free `monthly-summary-format` skill, and guided `onboarding` skill.
- **Modular NestJS Architecture (43 MCP Tools)**: Split REST endpoints into 8 focused controllers + modular `McpModule` (`ExpensesModule`, `OutingsModule`, `McpModule`) with **38 unit tests across 9 files**.
- **Variable Stack Awareness**: `health_check` cleanly reports `optionalServices.paperless.status: "disabled"` when Paperless is not deployed, never degrading core health.

## Breaking Changes (REST API)

If you called REST endpoints directly (Hermes uses `POST /api/mcp`, which is unaffected):

- `/api/expenses/installments/*` → `/api/installments/*`
- `/api/expenses/cards` → `/api/credit-cards`
- `/api/expenses/summary` → `/api/analytics/summary`
- New resource roots: `/api/members`, `/api/budgets`, `/api/recurring-expenses`, `/api/analytics`, `/api/outings`

## Upgrading from v1.x

1. Pull `v2.0.0` and ensure shared artifact folders exist:
   ```bash
   git pull origin main
   mkdir -p hermes/charts hermes/exports
   chmod +x scripts/setup.sh scripts/smoke-test.sh scripts/migrate.sh
   ```
2. If you run with `DB_SYNCHRONIZE=false` (recommended in production), run the automated migration script (creates a `pg_dump` backup first):
   ```bash
   ./scripts/migrate.sh --normalize-categories --backfill-owner "YourName"
   ```
3. Rebuild and verify:
   ```bash
   docker compose up -d --build
   ./scripts/smoke-test.sh
   ```
